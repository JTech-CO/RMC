# R.M.C. 2.0.1 — UI 가독성·스트로크 디자인 수정

작성일: 2026-09-06  
기준: 이 대화에서 전달한 `RMC-refactored-v2.0.0.zip`  
대상: 작성 내용이 아니라 RMC 애플리케이션의 메뉴·도구·상태·설정 UI

## 변경 요약

글자를 키우기 위해 전체 페이지를 확대하지 않고, UI 전용 `--ui-*` 토큰과 컴포넌트 스타일을 조정했다. 기본 다크모드와 기존 작업 흐름을 유지하면서 작은 고정폭 라벨, 낮은 대비, 둥근 버튼·패널을 정리했다. 원격 저장소에는 변경을 반영하지 않았다.

| UI 영역 | 2.0.0 기본값 | 2.0.1 기본값 |
| --- | --- | --- |
| File / Edit / Help 메뉴 | 12px | 16px |
| 주요 실행 버튼 | 11px; 모바일 HTML 버튼 10px | 16px |
| 파일명 | 11px 고정폭 | 16px 산세리프, 굵기 600 |
| 저장 상태 | 9px | 14px |
| Preview / HTML source 탭 | 11px | 16px |
| 패널 하단 안내 | 10px | 14px |
| 앱 하단 상태 표시줄 | 데스크톱 10px, 모바일 9px | 14px |
| 브랜드 설명 | 데스크톱 9px, 모바일 8px | 14px |
| 설정·확인창 본문 | 12px | 16px |
| 일반 조작 버튼 높이 | 주로 34–40px | 기본 44px |

신규 UI 크기는 기본 루트 글자 크기 16px에서의 값이다. UI 토큰은 `rem`을 사용하므로 사용자가 기본 글꼴 크기를 키우면 함께 확대된다. 공간이 부족하면 버튼·상태·메뉴를 재배치하고, 좁은 모바일에서는 Open과 Export MD 등 일부 직접 실행 버튼을 File 메뉴에서 이용하게 했다. 메뉴 항목 자체를 제거하지 않았다. 모바일 서식 버튼은 40×44px이고, 매우 좁은 패널에서는 서식 도구 줄 안에서 가로 스크롤할 수 있다.

## 색상과 형태

| 토큰 | 색상 | 용도 |
| --- | --- | --- |
| `--ui-bg` | `#090c10` | 앱 바탕 |
| `--ui-panel` | `#15191f` | 헤더·패널·대화상자 |
| `--ui-toolbar` | `#181e25` | 도구 영역 |
| `--ui-text` | `#f3f5f7` | 주요 라벨 |
| `--ui-muted` | `#c5ced8` | 보조 라벨 |
| `--ui-subtle` | `#bec8d5` | 비활성 안내 등 |
| `--ui-border` | `#697583` | 기본 1px 외곽선 |
| `--ui-border-strong` | `#a1afbf` | 강조·호버 외곽선 |
| `--ui-accent` | `#acd1ff` | 선택·포커스·주요 동작 테두리 |

UI의 주요 텍스트는 밝은 중성색으로 통일하고, 파란색은 선택·포커스 중심으로 제한했다. 저장 성공·주의·실패 상태는 밝은 상태색과 기존 텍스트를 함께 사용한다. 비활성 버튼은 불투명도를 낮추지 않고 점선 테두리로 표시한다. 선택 탭은 밝은 글자·변경된 배경·하단 3px 선으로 구분한다.

버튼·패널·메뉴·토스트·대화상자의 모서리는 0px로 변경했다. 아이콘 선 끝은 square, 선 접합은 miter로 설정했다. 로고·파비콘도 각진 외곽선으로 통일했다. 문서 안의 코드 블록 등 본문 요소의 기존 모서리 스타일은 이번 UI 변경 대상이 아니다.

## 변경하지 않은 부분

`css/document.css`는 원본과 바이트 단위로 동일하다. 기본 샘플 Markdown 문자열도 동일하며, 데스크톱 1440px와 모바일 390px에서 원본 캔버스의 글꼴·크기·색상·줄 간격·패딩 등을 비교했다. 에디터, 미리보기 문단·제목·표·코드, HTML 소스에서 검사한 스타일은 일치했다. UI가 차지하는 높이와 패널 간격은 조작성을 위해 달라졌다.

변환·정제·Worker·초안 저장 키·복사·내보내기 로직과 렌더러 의존성 설정은 유지했다. JavaScript의 동작 변경은 메뉴 키보드 이동에서 CSS로 숨겨진 모바일 전용 항목을 제외하는 처리다. 버전 표시는 2.0.1로 변경했다.

## 검증과 적용

구조 검사 70/70, Node 단위·HTTP 테스트 57/57, 격리 UI 검사 96/96을 통과했다. 13개 기본 뷰포트, 글꼴 확대, 좁은 패널, 메뉴·대화상자·키보드 이동을 점검했다. 정의된 일반 UI 텍스트 토큰 3종 × 주요 배경 4종의 12개 대비 조합은 최소 7.362:1이었다. 이는 특정 토큰 조합의 계산 결과이며 제품 전체의 접근성 인증이 아니다.

UI 화면은 실제 HTML/CSS와 고정 샘플 문서를 사용한 격리 렌더다. Markdown 변환기·Worker·저장소·실제 다운로드까지 실행한 E2E는 아니다. 실제 HTTP 브라우저 검사는 실행을 시도했지만 환경 정책으로 접속이 차단되었다. 세부 범위와 로그는 [QA 보고서](QA-REPORT.md)를 확인한다.

기존과 동일하게 압축 내부 `RMC/`의 내용물을 프로젝트 루트에 적용한다. `.git/`, 별도로 관리하는 `CNAME`, 로컬 환경 설정은 보존한다. 현재 브라우저 초안 키를 바꾸지 않았지만, 중요한 원문은 적용 전에 Markdown 파일로 내보내는 편이 안전하다.

```bash
npm run dev
npm run check:all
npm run test:ui
```

UI 검사는 Playwright와 Chromium 설치가 필요하다. 기본 실행 방법과 실호스팅 검증 명령은 README를 따른다.
